# Project 1: Data Cleaning
## Project Overview
This project focused on cleaning and preparing an e-commerce dataset for analysis. The goal was to improve data quality and ensure that the dataset was consistent, accurate, and ready for further analysis.
## Tools Used
- Microsoft Excel
- Power Query
## Data Cleaning Activities
The following data cleaning tasks were performed:
- Removed duplicate records.
- Identified and handled blank or missing values.
- Removed unnecessary spaces from the data.
- Standardized inconsistent data formats.
- Reviewed the dataset for inconsistencies.
- Prepared the cleaned dataset for exploratory data analysis.
## Key Outcome
The dataset was successfully cleaned and prepared for the next stage of the analysis process. The cleaned data provided a more reliable foundation for calculating metrics, identifying patterns, and generating business insights.
## What I Learned
This project strengthened my understanding of the importance of data quality in data analysis. I learned that cleaning data is an essential step before performing analysis because inconsistencies, duplicates, missing values, and formatting issues can affect the accuracy of analytical results.
I also gained practical experience using Excel and Power Query to efficiently prepare raw data for analysis.
## Conclusion
This project demonstrated my ability to identify and resolve common data quality issues and prepare an e-commerce dataset for further analysis. The cleaned dataset was subsequently used for exploratory data analysis and visualization.
