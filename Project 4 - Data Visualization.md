# Project 4: Data Visualization with Excel
## Project Overview
This project focused on transforming e-commerce data into an interactive and easy-to-understand dashboard using Microsoft Excel.
The dashboard covers e-commerce orders from January 2023 to June 2025 and presents key performance indicators, trends, and business insights relating to orders, order value, products, payment methods, and order status.
## Tools Used
- Microsoft Excel
- PivotTables
- Excel Charts
- Excel Formulas
- Slicers
## Dashboard KPIs
The dashboard presents four key performance indicators:
- **Total Orders:** 1,200
- **Total Order Value:** ₦1,264,762
- **Average Order Value:** ₦1,053.97
- **Unique Customers:** 1,189
## Dashboard Visualizations
### Orders by Order Status
A colunm chart was used to compare orders across different order statuses.
- **Cancelled:** 759 orders
- **Pending:** 724 orders
- **Delivered:** 690 orders
- **Returned:** 682 orders
- **Shipped:** 680 orders
Cancelled orders recorded the highest number of orders among the statuses displayed.
### Order Value by Payment Method
A bar chart was used to compare total order value across payment methods.
- **Credit Card:** ₦263,848
- **Online:** ₦262,443
- **Cash:** 259,443
- **Gift Card:** 246,324
- **Debit Card:** 232,361
Credit card recorded the highest order value among the payment methods displayed.
### Orders by Product
A column chart was used to compare the number of orders received for each product.
- **Chair:** 562 orders
- **Printer:** 542 orders
- **Laptop:** 535 orders
- **Desk:** 508 orders
- **Tablet:** 497 orders
- **Monitor:** 480 orders
- **Phone:** 411 orders
Chair recorded the highest number of orders.
### Order Value by Product
A bar chart was used to compare the total order value generated by each product.
- **Chair:** ₦195,620
- **Printer:** ₦195,613
- **Laptop:** 192,127
- **Tablet:** 186,569
- **Monitor:** 175,651
- **Desk:** 167,460
- **Phone:** 151,722
Chair and Printer generated almost the same total order value, with Chair recording a slightly higher value.
### Monthly Order Value Trend
A trend chart was used to visualize changes in order value over time from January 2023 to June 2025.
The highest monthly order value occurred in **June 2024**, followed by **May 2023**.
## Key Insights
1. **Chair and Printer generated the highest total order values, with each generating approximately ₦195.6K, in order value.
2. **Order value declined over the comparable January-to-June period from 2023 to 2025**, indicating a downward trend in sales value across the comparable months.
3. **Credit card recorded the highest average order value at ** 1,127.55, among the payment methods analyzed.
## What I Learned
This project improved my ability to communicate data through visualizations and dashboards rather than relying only on tables and calculations.
I gained practical experience in using PivotTables, Excel formulas, charts, and slicers to transform raw data into an interactive dashboard.

I also learned how to select appropriate visualizations for different business questions and how to present key findings in a clear and concise format.

## Conclusion

This project demonstrated how Microsoft Excel can be used to transform raw e-commerce data into an interactive data visualization dashboard.

The dashboard provides a visual overview of key business metrics and highlights patterns in order status, product performance, payment methods, and monthly order value, helping to turn data into actionable business insights.
