# Project 3: SQL Data Analysis
## Project Overview
This project focused on using SQL to analyze an e-commerce dataset and extract meaningful insights from the data. The analysis involved writing SQL queries to explore order records, calculate key metrics, and examine patterns across different aspects of the dataset.
## Tools Used
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- SQL
## Objectives
The main objectives of this project were to:
- Retrieve and explore data from the Orders table.
- Calculate key summary statistics using SQL.
- Analyze customer and order information.
- Examine payment methods and order statuses.
- Analyze coupon code usage.
- Practice aggregating and grouping data to identify patterns.
## SQL Analysis Performed
The following SQL techniques were used during the analysis:
- `SELECT` to retrieve data from the Orders table.
- `COUNT` to calculate the number of orders.
- `COUNT(DISTINCT)` to determine the number of unique customers.
- `SUM` to calculate total order value.
- `AVG` to calculate average order value.
- `GROUP BY` to summarize data by categories.
- `ORDER BY` to arrange results in ascending or descending order.
- Analysis of payment methods.
- Analysis of order status distribution.
- Analysis of coupon code usage.
## Key Findings
The SQL analysis provided insights into:
- The overall number of orders in the dataset.
- The total value of orders.
- The average order value.
- The number of unique customers.
- The distribution of orders across different payment methods.
- The distribution of different order statuses.
- The frequency of coupon code usage.
